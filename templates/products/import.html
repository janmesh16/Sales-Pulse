Maximum file size: 2MB. Format must be UTF-8 encoded CSV.
Required CSV Format & Columns

Your CSV file must include the following header row in exact sequence:

name,sku,category,cost_price,sell_price,stock_qty,reorder_level

Example Row:

Tata Tea Gold 250g,BEV-TEA-001,Beverages,110.00,140.00,25,5
  • name: Product descriptive name.
  • sku: Unique Stock Keeping Unit code (e.g. GRO-ATT-001).
  • category: Category name (automatically created if not existing).
  • cost_price & sell_price: Numbers with up to 2 decimal places.
  • stock_qty & reorder_level: Positive whole numbers.
